## Features

- An animated hero and **scroll-reveal** section transitions
- **Expanding cards** and an expanding navigation menu
- A scroll-aware navigation bar
- Developer bio, skills, and "Let's work together" contact sections
- A responsive layout

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

## Run locally

```bash
git clone https://github.com/dean1234533/Project-Portfolio.git
cd Project-Portfolio
open index.html
```
