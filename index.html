DB Workouts Website Redesign

Project Overview

This project involved redesigning and rebuilding a fitness website for a personal training business. The goal was to transform a basic template-style website into a modern, conversion-focused site that clearly communicates the brand, services, and booking process.

  • ★Weak call-to-action for visitors
  • ⭐Limited explanation of training services
  • ★Poor visual hierarchy and page structure
  • ⭐No clear path for users to book training sessions

What I Did

For this project, I redesigned and rebuilt the website to improve user experience, branding, and conversion flow.

The original site worked as a simple template but did not guide users toward booking training sessions or understanding the services offered. My goal was to create a clearer structure that would help visitors quickly understand the business and take action.

Improved Page Structure

I reorganised the layout to guide visitors through the site in a logical flow: introduction → services → testimonials → booking.

Stronger Call-to-Action

I introduced clearer call-to-action sections encouraging visitors to book a consultation or learn more about the training services.

Clear Service Presentation

Dedicated sections were added to explain the different training options available, helping users quickly find relevant information.

Improved Visual Hierarchy

The design was updated with better spacing, typography, and section organisation so that content is easier to read and navigate.

Mobile-Friendly Layout

The website was rebuilt with responsive design principles so it works well across mobile, tablet, and desktop devices.

Key Improvements

  • ⭐Modern hero section with a clear value proposition
  • ★Structured service sections explaining training programs
  • ⭐Stronger call-to-action encouraging consultation bookings
  • ★Client testimonials for social proof
  • ⭐Cleaner layout and improved readability
  • ★Responsive design for multiple screen sizes

Technologies Used

  • ⭐HTML
  • ★CSS
  • ⭐JavaScript
  • ★React
  • ⭐Vercel Deployment

What I Learned

  • ⭐How to redesign a website with user conversion in mind
  • ★Structuring landing pages to guide visitors toward a clear action
  • ⭐Improving visual hierarchy to make content easier to scan
  • ★Creating more professional UI layouts for real businesses

DB Workouts: Trainer-Client Management Platform

A full-stack app where personal trainers can manage clients, build workout plans, track nutrition, chat with clients, and keep notes—all in one place.

Project Screenshots

Project Demo Video

Web App Key Features:

  • ⭐ Secure login and registration with recovery
  • ★ Personalized dashboard for every trainer

Four Main Sections:

  • ⭐ Workouts: Build custom programs for clients
  • ★ Food Diary: Track client nutrition and meals
  • ⭐ Chat: Direct messaging with all your clients
  • ★ Notes: Quick reminders and key observations
  • ⭐ Workout builder adds exercises with details
  • ★ Form validation catches errors before saving
  • ⭐ Scroll-to-top button for easy navigation

Built With:

  • ⭐ HTML5, CSS3, and JavaScript on front end
  • ★ Firebase and supabase powering the back end
  • ⭐ Database stores users, workouts, and chats
  • ★ Secure authentication with password hashing
  • ⭐ Session management keeps users logged in
  • ★ Responsive design optimized for mobile use

Design:

  • ⭐ Clean interface with textured background
  • ★ Consistent red accent color throughout
  • ⭐ Large clickable cards with vibrant images
  • ★ Simple forms with clear descriptive labels
  • ⭐ Works beautifully on phones and tablets

Security:

  • ⭐ All authentication is handled by firebase
  • ★ Login required to access protected pages
  • ⭐ Automatic session timeouts for user safety
  • ★ Password reset option for account recovery

I built this to help trainers manage multiple clients without the hassle. Everything they need—workouts, nutrition, communication—is in one spot, making it easier to keep clients on track.
